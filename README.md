# Ambilight

Подсветка четырёх краёв монитора на адресной ленте и ESP32. Интерфейс встроен в ThodHUB; захват DXGI и сеть работают в отдельном процессе Windows x64.

Версия 1.0.7. Режимы: захват экрана, постоянный цвет, тёплый ночной свет, холодный дневной свет, дыхание, перелив. Точечная калибровка до 360 светодиодов, направление, начальный индекс, пропуски, глубина захвата, сглаживание, гамма, коррекция RGB и расписание. Выбор монитора скрыт, когда он один. Визуализацию можно выключить независимо от захвата.

## Данные

Настройки: `THODHUB_DATA_DIR/ambilight.json`. Ключ привязки: `device-secret.dat`, защищён DPAPI текущего пользователя Windows. Копия этого ключа не переносится на другую учётную запись/переустановку Windows; в таком случае нужна повторная привязка. Личные данные не входят в пакет. Прошивка хранит Wi-Fi, привязку и состояние в NVS ESP32; эти данные не входят в резервную копию хаба.

## Запуск и завершение

Рабочий процесс запускается хабом, использует JSON-RPC 2.0 по stdin/stdout, завершает захват и сеть при EOF. Переключение страниц хаба не останавливает подсветку. Закрытие хаба завершает процесс; через 3,5 секунды без пакетов ESP32 выключает свет. Физическая кнопка позволяет снова включить тёплый ночной свет без компьютера. Физическое выключение сохраняется и не отменяется кадрами.

Переключатель автозапуска регистрирует только `HKCU/Software/Microsoft/Windows/CurrentVersion/Run/ThodHUB.Ambilight`, запускающий стабильный путь хаба с `--launch ambilight`. Cleanup удаляет только принадлежащую приложению запись. Автозапуск по умолчанию выключен, службы и драйверы не устанавливаются.

## Сборка

Windows, .NET SDK 10 и существующий LLVM-MinGW. `scripts/build.ps1` собирает self-contained worker, нативный DLL захвата и ZIP для хаба. Сборка не устанавливает инструменты. Внутри ZIP — manifest в корне, локальный интерфейс, runtime, исходники прошивки и инструкции. Бинарная прошивка включается только после успешной сборки для конкретной платы.

## Ограничения проверки

Поддерживается захват локального рабочего стола через Desktop Duplication. Защищённый видеоконтент, защищённый рабочий стол Windows, HDR и некоторые полноэкранные режимы требуют отдельной проверки; абсолютная совместимость со всеми программами не заявляется. При недоступном захвате выводится причина, цвета гаснут, выполняется повторное подключение. HDR использует выдаваемый DXGI 8-битный кадр, отдельной HDR-калибровки нет.

Визуализация показывает рассчитанные цвета, а не подтверждённое свечение ленты. Сборка предназначена для ESP32-D0WD-V3 с flash 4 МБ. Цветовой порядок ленты, физическая кнопка и энкодер требуют проверки после подключения этих компонентов.
