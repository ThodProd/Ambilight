# Проверка пользователем

## Сейчас, без ленты

1. «Подсветка»: выберите «За экраном», перемещайте цветные окна к каждому краю монитора; наблюдайте цвет виртуальных LED. Проверьте яркость, выключение, ночной/дневной свет, постоянный цвет, дыхание и перелив. Отключите визуализацию — расчёт подсветки должен продолжаться.
2. «Калибровка»: задайте стороны, направление и начало; отметьте отдельные LED и пропуск, закройте/откройте модуль — конфигурация должна сохраниться. При двух мониторах проверьте выбор; при одном выбор скрыт. Проверьте расписание с ближайшим временем.
3. «Настройки» → «Реакция на экран»: перемещайте «Глубину захвата от края» — на мониторе должны подсветиться четыре полосы точно того же размера, что и реальная область захвата. Отпустите ползунок — полосы исчезнут; кнопка «Показать область захвата» оставляет их на экране до повторного нажатия. Лента должна реагировать на цвет у самого края без заметной задержки.
4. «Подключение»: поиск должен показать вашу ESP32; после привязки — состояние соединения. При отключённой плате поиск показывает отсутствие устройства. Проверьте автозапуск только по желанию. Реальные игры, HDR, сон/пробуждение и смена монитора проверяются на вашем ПК.

## Позже, с оборудованием

Проверить распиновку и питание, цветовой порядок ленты, точечную калибровку всех углов, задержку в играх, физическую кнопку, автономный ночной свет, энкодер, восстановление после смены IP и перезапуска ESP32. UDP-предпросмотр не подтверждает реальное свечение.

Не использовать рабочие данные для тестов и не считать этот список отчётом об уже выполненных проверках.
