# Проверка пользователем

## Проверка программы и оборудования

1. «Подсветка»: выберите «За экраном», перемещайте цветные окна к каждому краю монитора; наблюдайте цвет виртуальных LED. Проверьте яркость, выключение, ночной/дневной свет, постоянный цвет, дыхание и перелив. Отключите визуализацию — расчёт подсветки должен продолжаться.
2. С прошивкой 1.0.9 включите подсветку и закройте ThodHUB: через 3,5 секунды рамка должна перейти на автономный тёплый свет. Запустите хаб снова, выключите подсветку и закройте его: лента должна остаться выключенной.
3. «Калибровка»: введите общее число LED и количество служебных. Выберите угол LED 1 / DIN, направление LED 2 и три оставшихся угла. После сохранения проверьте зелёную змейку и нажмите «Завершить».
4. «Настройки» → «Реакция на экран»: перемещайте «Глубину захвата от края» — на мониторе должны подсветиться четыре полосы точно того же размера, что и реальная область захвата. Отпустите ползунок — полосы исчезнут; кнопка «Показать область захвата» оставляет их на экране до повторного нажатия. Лента должна реагировать на цвет у самого края без заметной задержки.
5. «Подключение»: поиск должен показать вашу ESP32; после привязки — состояние соединения. При отключённой плате поиск показывает отсутствие устройства. Проверьте автозапуск только по желанию. Реальные игры, HDR, сон/пробуждение и смена монитора проверяются на вашем ПК.

## Позже, с оборудованием

Проверить распиновку и питание, цветовой порядок ленты, точечную калибровку всех углов, задержку в играх, физическую кнопку, автономный ночной свет, энкодер, восстановление после смены IP и перезапуска ESP32. UDP-предпросмотр не подтверждает реальное свечение.

Не использовать рабочие данные для тестов и не считать этот список отчётом об уже выполненных проверках.
