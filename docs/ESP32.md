# Подключение ESP32

Подготовлены исходники и сборка для проверенного ESP32-D0WD-V3 (ESP32 Dev Module, flash 4 МБ). Ленты пока нет. Не загружайте эту сборку в ESP32-C3/S3: выберите правильную плату и GPIO.

Первая конфигурация `firmware/Ambilight/BoardConfig.h`: ESP32 DevKit / ESP32-WROOM-32, лента WS2812B GRB, D18 (GPIO18) — данные, D23 (GPIO23) — кнопка на GND с внутренней подтяжкой. Энкодер включён: D25 (GPIO25) — A/CLK, D26 (GPIO26) — B/DT, общий C — GND. Неподключённые входы удерживаются внутренними подтяжками. Поддерживаются 4–360 светодиодов. SK6812 RGBW можно настроить на четыре канала, отдельный белый канал в этой версии не используется.

Лента должна питаться от отдельного подходящего блока питания, а не от вывода ESP32. Земли объединяются. Питание, допустимый ток, сечение проводов, инжекция питания и согласование уровня данных подбираются по конкретной ленте. Физическая кнопка отключает свечение, а не питание схемы. Для автономного света ESP32 тоже должна получать питание независимо от выключенного компьютера.

Схема с обозначениями D-портов, питанием и кнопками: [Провода и питание](WIRING.md). Она также доступна в программе: «Подключение → Куда подключать провода».

## Сборка после установки инструментов

Официальные инструменты: https://docs.arduino.cc/arduino-cli/installation/ и https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html.

Требуется Arduino CLI и Arduino-ESP32 **3.3.4**. Сторонние LED/JSON библиотеки не требуются. Скрипт `scripts/build-firmware.ps1 -ArduinoCli <путь-к-arduino-cli.exe>` использует локальные каталоги проекта и только уже установленное ядро; автоматически установка не выполняется. Для этого рабочего места инструменты установлены в `.tools`, исходные архивы проверены по опубликованным SHA-256/SHA-512. Из-за HTTP 403 на downloads.arduino.cc применена официальная ручная установка ядра из GitHub-релиза Espressif, FQBN `local:esp32:esp32`; исходники ядра не изменены. В обычной установке используется `esp32:esp32:esp32`.

После подтверждения платы: собрать, подключить плату USB, выбрать порт. Скрипт сборки **не прошивает** контроллер. Для прошивки нужна отдельная команда с верным COM-портом и выбранной платой.

## Первый запуск

1. В USB-мониторе 115200 прочитайте имя `Ambilight-xxxxxx` и пароль её Wi-Fi.
2. Подключитесь к этой сети, откройте `http://192.168.4.1`, задайте домашний Wi-Fi 2,4 ГГц и запишите код привязки.
3. Вернитесь в домашнюю сеть на компьютере. В Ambilight откройте «Подключение» — поиск запускается автоматически.
4. Выберите найденное устройство, введите код, нажмите «Подключить». Позже соединение восстанавливается автоматически.
5. Настройте число LED и выполните точечную калибровку. «Подсветить» зажигает один LED, затем нажмите его место на схеме, глядя на монитор спереди.

Если настройка закрылась, удерживайте кнопку 5 секунд. Короткое нажатие включает/выключает свет. После потери потока свет гаснет. Кнопкой без ПК включается тёплый ночной свет; при отключённом свете подключение остаётся активным. Энкодер меняет яркость на 2% за шаг, состояние сохраняется после остановки вращения.

Пока отдельная кнопка не подключена, через USB Serial 115200 доступны `STATUS` (состояние) и `SETUP` (открыть настройку), `CLOSESETUP` (закрыть настройку). Сервисная команда `WIFI <base64 SSID> <base64 password>` задаёт Wi-Fi без переключения сети компьютера, `PAIRCODE` выдаёт код текущего сеанса настройки. Эти команды доступны только через физический USB; пароль не выводится обратно. Не сохраняйте USB-журналы с кодами и паролями в публичный репозиторий.

Убедитесь, что роутер не изолирует Wi-Fi-клиентов. Поиск использует UDP 19446, кадры UDP 19447, управление HTTP 80. Программа не меняет настройки брандмауэра автоматически. Если broadcast заблокирован, используйте поле IP.

Сеанс настройки открыт 5 минут. Затем код аннулируется, формы настройки недоступны, защищённая паролем точка доступа скрывается. Радио AP+STA остаётся инициализированным, чтобы повторное открытие настройки не вызывало перезапуск на этой плате. Flash: DIO, 40 МГц.

## Состояние подключения

«ESP32 подключена по Wi-Fi» означает, что сохранённый ключ принят устройством и программа получает его состояние по сети. IP — локальный адрес платы. ID — постоянный идентификатор, не PIN. Повторно вводить код при каждом запуске не нужно.

Код привязки берётся со страницы настройки ESP32, действует до 5 минут и используется один раз. После успешной привязки он аннулируется. Для другой платы или восстановления доступа раскройте «Подключить другую ESP32 / привязать заново». Отказ 403 означает неверный/использованный код, закрытый сеанс либо исчерпанные попытки. Откройте новый сеанс настройки; сохранённая привязка при отказе остаётся прежней.

Приложение 1.0.8 включает совместимую прошивку 1.0.7. Для изменения экрана подключения перепрошивка не нужна.
