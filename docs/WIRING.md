# Провода и питание Ambilight 1.0.7

Схема для ESP32 DevKit и **WS2812B GRB на 5 В**. D18 означает GPIO18, D23 — GPIO23; это не номера ножек в ряду. Маркировка конкретной платы может отличаться: при несовпадении сверяйте её распиновку. Для ленты на 12/24 В эта схема питания не подходит.

| Подключение | Контакты |
|---|---|
| Сигнал ленты | **D18** → преобразователь 74AHCT125 → резистор 330 Ом → **DIN** первого LED. Стрелки идут дальше по ленте. |
| Плюс питания ленты | **+5V ленты → +5 В отдельного блока питания**. |
| Общая земля | **GND ESP32 ↔ GND ленты ↔ минус блока питания**, также GND преобразователя. |
| Питание ESP32 | **USB платы**. Для работы с выключенным ПК — отдельный USB-адаптер 5 В. При USB-питании не подключайте другой источник к VIN/5V. |
| Кнопка без фиксации | Между **D23 и GND**. Питание на кнопку не подаётся, подтяжка уже включена. |
| Механический энкодер яркости | **A/CLK → D25**, **B/DT → D26**, **C → GND**. Это энкодер, не потенциометр. У модуля с VCC питание — только **3V3**, GND — общий. |
| Нажатие на энкодер | Если есть SW: **SW → D23**, общий контакт кнопки → **GND**. Можно вместо отдельной кнопки или параллельно ей. |

В прошивке 1.0.7 входы D25/D26 включены и имеют внутренние подтяжки: энкодер можно подключить позже. Если направление вращения обратное, поменяйте местами A и B при отключённом питании.

Короткое нажатие включает или выключает свет, удержание 5 секунд открывает настройку Wi-Fi. Без ПК кнопка включает тёплый ночной свет. BOOT и EN служат загрузке и перезапуску платы, не управлению подсветкой. D0–D3 не используйте вместо D18/D23: у ряда ESP32 это линии flash.

## Преобразователь уровня

Для **SN74AHCT125, DIP-14** (у готового модуля смотрите его собственную схему):

| Контакт микросхемы | Подключение |
|---|---|
| 1A, ножка 2 | D18 ESP32 |
| 1Y, ножка 3 | Через 330 Ом к DIN; резистор рядом с первым LED |
| 1OE, ножка 1 | GND |
| GND, ножка 7 | Общая земля |
| VCC, ножка 14 | +5 В блока ленты |
| Остальные OE: 4, 10, 13 | +5 В |
| Остальные входы A: 5, 9, 12 | GND |
| Остальные выходы Y: 6, 8, 11 | Не подключать |

Между VCC и GND рядом с микросхемой — 0,1 мкФ. Преобразователь выдаёт сигнал 5 В для ленты, вход ESP32 остаётся 3,3 В. [Распиновка Texas Instruments SN74AHCT125](https://www.ti.com/lit/ds/symlink/sn74ahct125.pdf).

## Питание

Лента не питается через D-порты или 3V3 ESP32. У её входа установите электролит 500–1000 мкФ на 6,3 В или выше: плюс к +5 В, минус к GND. Общая земля обязательна даже при двух источниках. Собирайте при отключённом питании; блок ленты включайте до контроллера. [Рекомендации Adafruit](https://learn.adafruit.com/adafruit-neopixel-uberguide/best-practices).

Ток блока, предохранитель и провода подбираются по числу LED и паспорту ленты. Для старых WS2812B максимум белого на 100% — до 60 мА на LED: 96 LED могут потребовать 5,76 А, нужен запас. Современные варианты могут потреблять меньше. Программная яркость не заменяет защиту питания. Для длинной ленты питание подводится дополнительно по её длине. [Расчёт питания Adafruit](https://learn.adafruit.com/adafruit-neopixel-uberguide/powering-neopixels).

ESP32 питается от одного источника. Здесь выбран USB, поэтому VIN/5V остаются свободными. [Espressif: питание и контакты DevKitC](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html).

Лента, внешняя кнопка и энкодер пока не подключены: их физическая проверка ещё предстоит.
