Что проверить, пока лента не подключена

Цветные точки по контуру — будущие светодиоды. Центр монитора — схема, а не копия рабочего стола. Включите подсветку и визуализацию, поднимите яркость.

  1. Выберите «Один цвет», затем красный: все точки должны стать красными.
  2. Выберите «Перелив»: цвета точек должны плавно меняться.
  3. Выберите «За экраном» и переместите яркое окно к краю настоящего экрана: точки на этой стороне должны изменить цвет. На тёмном фоне они тоже тёмные.

Если включено ночное расписание, временно отключите его для этой проверки. На самой ESP32 ничего загораться не обязано: встроенный светодиод платы не заменяет ленту. Реальные положения LED калибруются после её подключения.

Сведения об устройстве

Привязка к компьютеру

Выполняется один раз. При обычном запуске сохранённая ESP32 подключается автоматически.

  1. Если ESP32 ещё не настроена, загрузите прошивку и подключите её к домашнему Wi-Fi через сеть Ambilight и страницу 192.168.4.1.
  2. На странице настройки ESP32 прочитайте шестизначный код привязки. Он действует до 5 минут и используется один раз.
  3. Вернитесь в домашнюю сеть, выберите найденную ESP32 и введите этот код.

Чтобы открыть настройку заново: удерживайте внешнюю кнопку 5 секунд. Пока кнопки нет — команда SETUP через USB, затем PAIRCODE для получения кода. Перепрошивать плату не нужно.

Куда подключать провода

Для ESP32 DevKit и ленты WS2812B на 5 В. D18 здесь означает GPIO18, D23 — GPIO23. Ориентируйтесь по надписям на плате, а не по номеру ножки в ряду. Если маркировка другая, сначала сверьте распиновку своей платы.

D18→74AHCT125

Что подключаемКуда идёт провод
Сигнал лентыD18 (GPIO18) → преобразователь уровня → резистор 330 Ом → DIN первого LED. Стрелки ленты идут от входа дальше по ленте.
Питание ленты+5V ленты → +5 В отдельного блока питания. GND ленты → минус блока. Лента не питается от D-портов или 3V3 платы.
Общая земляGND ESP32 ↔ GND ленты ↔ минус блока питания и GND преобразователя.
Питание ESP32USB платы. Для ночного света при выключенном ПК — USB от отдельного адаптера 5 В. При питании через USB не подключайте второй источник к VIN/5V.
Кнопка включенияОбычная кнопка без фиксации: один контакт → D23 (GPIO23), второй → GND. Питание на кнопку не подаётся.
Регулятор яркостиМеханический энкодер: A/CLK → D25, B/DT → D26, общий C → GND. Для модуля с VCC — только 3V3. Не потенциометр.
Кнопка энкодераЕсли есть SW: SW → D23, общий → GND. Может заменить отдельную кнопку или работать параллельно ей.

Короткое нажатие — включить/выключить свет. Удержание 5 секунд — открыть настройку Wi-Fi. Без компьютера кнопка включает тёплый ночной свет; вращение энкодера меняет яркость.

Преобразователь и питание — подробнее

Для 74AHCT125 в корпусе DIP-14: D18 → вход 1A (ножка 2), выход 1Y (3) → 330 Ом → DIN. 1OE (1) и GND (7) → общая земля, VCC (14) → +5 В блока ленты. Неиспользуемые OE (4, 10, 13) → +5 В, входы A (5, 9, 12) → GND, выходы оставить свободными. Между VCC и GND рядом с микросхемой — 0,1 мкФ. У готового модуля ориентируйтесь на его схему, номера корпуса к нему не относятся.

У входа ленты: электролит 500–1000 мкФ, не менее 6,3 В, плюс к +5 В, минус к GND. Ток блока, сечение проводов и предохранитель подбираются по длине и паспорту ленты. Для старых WS2812B расчётный максимум — до 60 мА на LED при белом 100%; 96 LED — до 5,76 А, нужен запас. Ограничение яркости в программе не заменяет защиту питания.

Все провода подключайте при выключенном питании. Для ленты на 12/24 В эта схема питания не подходит. BOOT и EN на ESP32 не являются кнопками подсветки. D0–D3 не используйте вместо D18/D23.

Сохранено

День и ночь

Ночью — тёплый свет, днём — выбранный сценарий. Расписание использует время Windows. При потере связи свет гаснет. Кнопкой на ESP32 можно включить ночной свет без компьютера.

Запуск и работа

При входе откроется хаб с Ambilight. После закрытия хаба управление переходит к ESP32: кнопка и ночной свет работают автономно.

Реакция на экран

Захват рабочего стола DXGI. При перемещении ползунка глубины полосы захвата подсвечиваются прямо на мониторе. Защищённое видео может быть недоступно; HDR и отдельные игры требуют проверки на вашем оборудовании.
